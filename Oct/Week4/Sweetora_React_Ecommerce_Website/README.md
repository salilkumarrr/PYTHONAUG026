# Sweetora — React e-commerce frontend

A responsive Indian sweets store frontend built with React, Vite and React Router DOM.

## Run the project
1. Install Node.js LTS on your laptop.
2. Extract this ZIP and open the extracted folder in VS Code.
3. Open VS Code Terminal in this folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown in the terminal (usually http://localhost:5173).

## Features
- Home page, product listing, category filters and product search
- Wishlist
- Add to cart, quantity controls and remove item
- Registration, sign-in and sign-out demo
- Checkout form with address and payment selection
- Order confirmation page
- Order history
- Cart, demo account, wishlist and orders saved in browser localStorage
- Responsive mobile layout

## Important
This is a frontend demonstration only. Authentication is not secure, there is no backend/database, and no real payment is processed. Product images are remote Unsplash links and need an internet connection.
